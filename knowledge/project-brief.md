# Project Brief — Original Context

Agentic Campaign Orchestrator — autonomous digital media buyer agent.

The system monitors active ad campaigns, detects when cost-per-click (CPC) is too high, and autonomously takes action — like reallocating the budget to a better-performing channel or pausing a failing ad.

Core architecture goals:
- RAG reasoning engine that pulls context from past campaign performance data and brand guidelines
- MCP servers to securely interface with mock ad network APIs (Google Ads, Meta), allowing the AI to safely "take action" on external systems
- End-to-end campaign management automation

Instead of a simple analytics dashboard, this is an autonomous agent that acts as a digital media buyer. The industry is currently heavily focused on creating agents that can handle end-to-end campaign management.

User goals: build to scale and monetise.
